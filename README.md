# SM3 Research

国密 SM3 哈希算法研究仓库。

## 简介

SM3 是中国国家密码管理局发布的一种密码散列函数标准（GM/T 0004-2012），输出 256 位（32 字节）摘要值，广泛用于数字签名、消息认证等领域。

## 特性

- 遵循 SM3 标准（GM/T 0004-2012）
- 输出 256 位摘要
- 适合国密算法学习与工程实践
